# 像素冒险 · 3D 版（Pixel Adventure 3D）

原版 2D 像素平台跳跃游戏的 **Three.js 3D 重制版**，完整保留原作玩法。

## 🎮 在线试玩

**[https://wangzixuanshijiu.github.io/pixel-adventure/](https://wangzixuanshijiu.github.io/pixel-adventure/)**

打开即玩，无需下载、无需联网（Three.js 引擎已内联进单文件）。

## 🕹️ 操作

| 按键 | 功能 |
|---|---|
| `W A S D` | 移动 |
| `空格` | 跳跃（含土狼时间与跳跃缓冲） |
| `E` | 与 NPC 对话 |
| `I` | 打开背包 / 合成面板 |
| `R` | 重置当前关卡 |
| `C` | 视角回正 |
| 鼠标拖动 | 旋转视角 |
| 滚轮 | 缩放 |

## ✨ 玩法内容

- **3 个关卡**：入门 → 进阶 → 挑战，关卡地图完全沿用原版
- **合成系统**：生命药水、疾风靴、弹跳手套、铁甲、铁剑（5 个配方）
- **5 种材料**：木材 / 石头 / 铁矿 / 水晶 / 草药
- **4 位 NPC**：村长爷爷、铁匠大叔、森林女巫、神秘旅者
- **隐藏支线**：第 2 关携带水晶靠近封印墙，可解除封印并开启秘密房间
- **敌人与机关**：巡逻怪（可踩踏）、飞行怪、尖刺、弹跳弹簧
- 3 格生命值、无敌闪烁、水晶护符闪避等机制

## 🛠 技术实现

- **Three.js r160**（已内联，单文件离线可运行）
- 静态方块采用 **InstancedMesh** 实例化渲染，大幅降低 draw call
- **程序化像素贴图**（Canvas 生成草地 / 泥土 / 红砖纹理），保留原汁原味像素风
- 第三人称相机：平滑跟随、平滑缩放、防穿墙收缩、受伤震动
- 手感优化：跳跃缓冲 + 土狼时间；反馈优化：落地扬尘、粒子特效
